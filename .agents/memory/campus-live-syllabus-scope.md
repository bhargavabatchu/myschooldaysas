---
name: Campus Live syllabus scope
description: The approved ownership and material format for class syllabi.
---

Keep each syllabus shared across all sections of the same class. Organize it by subject, lessons, and topics; attach learning materials as document or video links rather than uploads.

**Why:** the user chose a class-shared syllabus and link-based materials.

**How to apply:** preserve one curriculum per class and subject when extending learning content; do not fork copies by section or change this into file uploads without confirmation.
